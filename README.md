# 홀덤 도장 3.0

나상균 제작 · 010-7529-5945

‘한 판마다, 한 수 더.’ 무료 가상 칩으로 플레이하고, 선택 당시의 정보로 복기하는 한국어 홀덤 학습 게임입니다.

## 실행과 배포

- `index.html`은 외부 라이브러리 없이 직접 열어 플레이할 수 있는 단일 파일입니다.
- 웹 배포는 `npm ci` → `npm run build`로 생성한 `dist/`를 사용합니다.
- 개발 서버: `npm run dev` → http://127.0.0.1:4173 (먼저 build 실행)
- Vercel은 `vercel.json`의 buildCommand와 outputDirectory를 사용합니다. 기존 프로젝트에 다른 수동 설정이 있다면 일치시켜 주세요.
- `/Index.html`은 `/index.html`로 연결됩니다. 저장소에는 Windows에서 충돌하는 대소문자 파일이 기존부터 존재하므로 두 진입 파일의 내용을 동일하게 유지합니다.
- 배포된 뒤 `/`, `/Index.html`, `/manifest.webmanifest`, `/sw.js`, 아이콘을 확인합니다.

## 제품 구성

- 4인 코치 연습실, 6인 토너먼트, 헤즈업 스파링
- 토너먼트는 8판마다 블라인드 상승, 탈락자 제외, 헤즈업 행동 순서 적용
- 10개 학습 과정과 확인 문제, 24개 상황 훈련, 오답 재학습
- 포지션별 입문 차트 169칸, 카드 예시로 보는 족보, 팟 오즈 실험실
- 선택 전 코치 설명을 저장한 복기, 최근 40판 기록, JSON 내보내기
- 플레이·훈련·복기 기반 XP, 학습 벨트, 일일 루틴, 성취 기록
- 소리·속도·4색 카드·코치 힌트 설정, 키보드 조작, 모바일 하단 메뉴
- 진행 중인 판의 자동 저장과 복원, 학습/설정/백그라운드에서 플레이 일시 정지
- PWA 설치, 오프라인 앱 셸, 앱 아이콘, 공유 이미지

## 구조

- `src/engine.js`: DOM과 독립된 게임 엔진, 족보, 팟 분배, AI 공개 정보 뷰, 학습용 분석
- `src/content.js`: 검토 가능한 한국어 학습 콘텐츠
- `src/app.js`: 화면, 로컬 저장, 진행 흐름
- `src/styles.css`: 반응형 디자인과 접근성
- `src/index.html`: 메타데이터와 진입 템플릿
- `scripts/build.mjs`: 위 소스를 단일 HTML과 배포 폴더로 조립
- `public/`: 서비스 워커, 매니페스트, 아이콘, 공유 이미지
- `tests/`: 규칙/저장/브라우저 검증

`index.html`을 직접 고친 뒤 build하면 변경이 덮어써집니다. 유지보수는 `src/`에서 합니다. 제작자 정보는 `aboutDialog()`에서 수정합니다.

## 검증

`npm test`: 족보·키커·사이드팟·동점 나눔·최소 레이즈·짧은 올인·헤즈업·칩 보존·AI 정보 격리 및 600판 자동 플레이.

`npm run test:ui`: PC Chrome에서 실제 클릭으로 한 판 진행, 올인, 저장/새로고침, 퀴즈·오답·복기·학습 완료, 169칸 차트, 확률 실험실, 모바일 레이아웃, 제작자 연락처, PWA 오프라인을 검사합니다. 로컬 Chrome과 개발 서버가 필요합니다. CI는 Playwright Chromium을 설치합니다. 스크린샷과 결과는 `artifacts/`에 남습니다.

## 학습 모델의 범위

- 가상 칩 전용. 결제, 환전, 실제 상대와의 온라인 멀티플레이는 없습니다.
- AI는 자신의 카드와 공개된 카드·칩·행동만 전달받습니다. 상대의 실제 개인 카드와 남은 덱을 받지 않습니다.
- 코칭과 시작 패 차트는 휴리스틱입니다. GTO 솔버나 전문 전략 엔진이 아닙니다.
- 지분 추정은 보이지 않는 카드를 무작위로 뽑은 몬테카를로 결과입니다. 상대의 베팅 범위를 모델링한 정확한 승률이 아닙니다.
- 복기 설명은 행동 전에 저장하며 결과를 근거로 판정을 바꾸지 않습니다. 승패에 따라 ‘판단 점수’를 부여하지 않습니다.
- 복기와 진도는 브라우저 로컬 저장입니다. 계정·클라우드 동기화는 없습니다. 내보내기는 보관용 JSON이며 자동 가져오기 기능은 아직 없습니다.
- 기존 `holdem_dojo_v8` 또는 `holdem-dojo-4p-v1`의 XP는 새 버전 최초 실행 시 승계합니다. 기존 키는 지우지 않습니다. 서로 다른 엔진의 진행 중인 판과 이전 학습 통계는 새 기록으로 전환하지 않습니다.

베팅·쇼다운 규칙 검토 출처: [Poker TDA](https://www.pokertda.com/view-poker-tda-rules/). 대회 운영 규칙 전체를 구현했다는 의미는 아닙니다. 토너먼트는 앱 내부의 간소화된 무앤티 연습 형식입니다.

## 나중에 앱으로 확장하기

현재는 설치 가능한 웹앱(PWA)입니다. `capacitor.config.json`에 앱 래퍼용 이름·ID·웹 빌드 경로를 준비했습니다. 네이티브 Android/iOS 프로젝트나 스토어 제출용 서명 파일은 생성하지 않았습니다.

다음 단계에서 Capacitor를 설치하고 Android/iOS 프로젝트를 추가하면 같은 `dist/`와 게임 엔진을 사용할 수 있습니다. 배포 전 앱 ID, 플랫폼별 안전 영역, 백그라운드 복원, 접근성, 저장 마이그레이션, 개인정보 문서와 스토어 메타데이터를 기기에서 검증해야 합니다. 온라인 멀티플레이를 추가할 때는 덱·행동 검증을 신뢰 가능한 서버에서 처리해야 합니다.
